📝 Voice Commands

  • "Add [task name]" - Add a new task
  • "List tasks" / "Show all" - List all tasks
  • "List active" - Show active tasks only
  • "List completed" - Show completed tasks only
  • "Complete [task number]" - Mark task as done
  • "Delete [task number]" - Remove a task
  • "How many tasks?" - Get task count
  • "Clear completed" - Remove done tasks
  • "Help" - Show available commands
